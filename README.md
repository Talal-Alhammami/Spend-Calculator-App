# مصروفي (Masroufi)

تطبيق إدارة مصروفات ذكي (PWA): بدون تسجيل، يعمل بدون إنترنت، وكل البيانات على جهاز المستخدم.
موقع ثابت (HTML + JS) بدون أي build أو مكتبات.

## التشغيل محلياً
```bash
python -m http.server 8080        # أو: npx serve .
# افتح http://localhost:8080
```
> لا تفتح `index.html` مباشرة بالنقر المزدوج؛ الـ Service Worker يحتاج http/https.

## النشر على Vercel
1. ارفع المستودع على GitHub.
2. Vercel ← Add New Project ← اختر المستودع.
3. Framework Preset: **Other** — Build Command: فارغ — Output Directory: `./`
4. Deploy. كل `git push` على `main` ينشر تلقائياً.

## الهيكل
| الملف | الوظيفة |
|---|---|
| `index.html` | الواجهة والتصميم |
| `app.js` | المنطق كاملاً (عربي / English / Deutsch / Türkçe) |
| `countries.js` | 200 دولة مع عملاتها (الأسماء تُترجم تلقائياً) |
| `sw.js` | العمل Offline (network-first) |
| `manifest.webmanifest`, `icons/` | التثبيت كتطبيق |
| `vercel.json` | هيدرز الكاش والأمان |

## Supabase
غير مربوط في هذا الإصدار (حسب PRD: لا حساب ولا مزامنة سحابية في v1).

## الأعلام
تُحمَّل من flagcdn.com عند أول عرض، ثم تُخزَّن للعمل بدون إنترنت. إذا تعذّر التحميل يظهر رمز الدولة بدلها.

## تعدد العملات والحسابات
- كل حساب له عملة ودخل شهري. المصروف يُسجَّل على حساب محدد بعملته.
- الإجمالي يُحوَّل للعملة المحلية بأسعار تقريبية (السعر الوسطي) من open.er-api.com، وإذا ما توفّر سعر يُستخدم fawazahmed0/currency-api. الأسعار تتحدّث كل 6 ساعات.
- يمكن إدخال سعر يدوي لأي عملة من الإعدادات (1 USD = X)، ويتقدّم على السعر التلقائي.
